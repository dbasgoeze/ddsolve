ddsolve
=======

Expectation-Based Probabilistic Program Verifier.

This package provides tools for verifying probabilistic programs using
Extended Arithmetic Decision Diagrams (XADDs) and Extended Binary Decision
Diagram (XBDDs). It supports multiple verification calculi including
weakest precondition (wp), weakest liberal precondition (wlp), and a
Dice-based evaluator.
